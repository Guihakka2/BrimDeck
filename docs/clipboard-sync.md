# 剪贴板同步（开发中）

在“设置 → 中转站 → 剪贴板同步”中连接局域网设备或手机输入法。自动同步默认关闭，文字单条最多 256 KiB（UTF-8）。局域网支持图片，微信与豆包连接目前只支持文字。文件、历史记录和常用语暂不支持同步。

## BrimDeck 局域网同步

1. 两台 Windows 电脑连接到同一局域网并打开 BrimDeck。在一台电脑上选择“创建邀请码”。如果有多个可用地址，请按网卡名称和子网选择与另一台电脑同子网的 IPv4 地址。如果只有一个可用地址，应用会自动选中。
2. 在另一台电脑上选择“输入邀请码”，输入后点击“连接”。邀请码两分钟内有效，成功配对后不能再次使用。请只将它提供给要配对的设备。
3. 在两台电脑上分别开启“自动同步文字和图片”。连接期间新复制的内容会加密传到另一台电脑，并写入其系统剪贴板。图片以 PNG 发送，单张最多 8 MiB、单边最多 8192 像素、总像素最多 16,777,216。旧版对端仍可同步文字。断线期间的复制不会在重连后补发。

局域网同步只监听选定的私有 IPv4 地址，使用 TLS 直连，无需互联网账号或中继。加入方自动尝试与邀请地址同子网的接口，并在本机网络变化后重新选择。第一版支持一对设备，保存邀请方配对时的地址和端口。如果邀请方更换了 IPv4 地址，请在两端解除配对后重新连接。关闭任一端的自动同步可停止传输。

## 微信输入法

通过六位配对码连接。配对窗口可以输入其他设备的配对码，也可以显示本机配对码，并由用户确认请求连接的设备。

在 Windows 版微信输入法上观察到，配对成功后官方客户端可能自动开启个人词库、常用语、AI 录音笔及剪贴板同步。请在微信输入法中检查各项开关。

已完成跨电脑双向文字同步验证，包含中文、多行和表情。本机默认名称为 `BrimDeck + 计算机名`，连接前可修改；手机修改设备名称后，本机可以读取服务端返回的名称。已连接设备的主动改名尚未实现。本机发码后的完整确认流程仍需进一步实机验证。

## 豆包输入法

使用电脑已安装的 Chrome 或 Edge，通过独立浏览器窗口登录豆包账号，不需要安装电脑端豆包输入法，也不内置 WebView2。优先使用受支持的默认浏览器；登录完成后关闭独立窗口。

账号登录和设备同步权限是不同状态。登录后可选择“检查同步权限”，只读取服务端返回的本机权限，不启用同步，也不读取剪贴板。此前独立登录的测试设备没有获得剪贴板同步权限，读取剪贴板的请求返回业务错误 `900102010`。独立连接后的双向同步和设备启用流程仍待验证。

## 数据与限制

- 连接信息通过 Windows 当前用户的数据保护机制加密保存在 BrimDeck 数据目录内，不读取已安装输入法的账号文件。换电脑后需要重新登录或配对。
- 启用同步不会上传当时剪贴板中的旧内容，也不会将服务端旧内容写入剪贴板。
- 剪贴板排除应用和隐私标记适用于本机复制监听；收到的文字会写入系统剪贴板，开启历史记录时也会进入 BrimDeck 历史。
- 断开连接只移除 BrimDeck 本地连接信息；需要移除远端设备时，请在对应输入法中操作。
- 本功能仍处于开发阶段，已连接设备主动改名、常用语同步和豆包独立设备启用尚未完成。
